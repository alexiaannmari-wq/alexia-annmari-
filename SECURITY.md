# Security Policy

## Supported versions

Security fixes are applied to the latest commit on the `main` branch of this repository.

Deployment, form providers, and third-party integrations configured in this project are the maintainer’s responsibility to keep secure and up to date.

## Reporting a vulnerability

If you discover a security issue in this repository (not in hosting setup or third-party account configuration alone), please report it privately:

- Open a [GitHub Security Advisory](https://github.com/alexiaannmari-wq/alexia-annmari-/security/advisories/new) on this repository, **or**
- Email the maintainer if you prefer not to use GitHub advisories.

Please include:

- A description of the issue and its potential impact
- Steps to reproduce
- Any suggested fix, if you have one

Please do **not** open a public issue for undisclosed security vulnerabilities.

We aim to acknowledge reports within a few business days and will work with you on a reasonable disclosure timeline.
